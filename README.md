# zerotrust

Just a p2p messaging app without any server

# Usage
- Install Tailscale
- Create a network on tailscale and ask people to join it
- When you want to chat with someone, enable tailscale (it should act as a VPN)
- Open the app (V3.0/zerotrust.apk) and select server or client (one have to choose server ad the other one client)
- select a port if you are the server
- write the ip of the person you want to text with (written next to his device in tailscale, it should be 100.x.x.x or something like that) and the port the server has selected
- the the connection should be ok and you can chat, the chat end when someone quit the app, no logs and completely p2p
